# 懒羊羊大王群管（AstrBot 插件）

支持 AstrBot `>=4.16,<5` 与 QQ OneBot v11（NapCat / Lagrange）。六张菜单 JPG 已原样随插件打包；插件不会引用电脑上的外部图片路径。

## 安装

1. 将整个 `astrbot_plugin_lazy_sheep` 文件夹放入 AstrBot 的 `data/plugins/` 目录，或压缩后在 AstrBot WebUI 的插件页安装。
2. 在插件管理页安装 `requirements.txt` 中的依赖并重载插件。
3. 将机器人设为群管理员；“上管/下管”通常还要求机器人账号本身为群主。
4. 在插件设置中按需调整禁言分钟数、时区、游戏倒计时和语音并发数。

## 菜单

直接发送：`菜单`、`群管`、`保安`、`统计`、`村规`、`乐园`，会分别回复对应的原始菜单图。

## 群管与保安

- 管理员命令：`上管 @成员`、`下管 QQ号`、`安静`、`说话`、`撤回`（回复一条消息）、`撤回 消息ID`、`撤回 @成员 N` / `撤回 QQ号 N`（撤回该成员最近 1–100 条消息）、`禁言 @成员 10`、`解禁 @成员`、`踢回 @成员`。`说话`会先确认当前群确实开启了全员禁言；未开启时不会调用解除命令。
- 名单命令：`拉白/删白/拉黑/删黑 @成员或QQ号`。白名单免于本插件保安与村规；黑名单成员会被立即及后续入群时踢出。
- 保安命令：`开链接撤回`、`开链接禁言`、`关闭链接`；卡片、号码、图片、二维码同理。链接保安识别带协议链接、`www.`、裸域名/短链、IPv4 地址，以及分享、Markdown、JSON/XML 卡片中的跳转地址；二维码只拦截二维码图片，不影响普通图片。
- 村规命令：`加撤回词 关键词`、`加禁言词 关键词`、`加踢人词 关键词`，并用相同格式将“加”改为“删”删除。

群管、保安与村规配置仅群主、群管理员或 AstrBot 管理员可以执行。

## 群白名单开机

群白名单总开关默认开启：只有执行过 `群开机` 或已被管理员登记的群能使用机器人。AstrBot 管理员可发送 `关闭群白名单` 临时允许所有群，或发送 `开启群白名单` 恢复限制；群主/群管理员在当前群发送 `群开机` 或 `群关机`，AstrBot 管理员也可以使用 `加群白名单 群号`、`删群白名单 群号` 和 `群白名单` 管理指定群。

群主和群管理员默认免受保安、村规关键词处理，不需要逐个执行 `拉白`。

## 统计与乐园

- `我的发言`、`发言日榜`、`发言周榜`、`发言月榜`、`查发言图 [@成员/QQ号]`。
- `签到`、`签到排行`、`我的邀请`、`邀请排行`、`查邀请图 [@成员/QQ号]`。
- `赛车游戏` 后发送 `选车 1` 至 `选车 6` 免费竞猜。
- `谁是卧底`、`加入卧底`、`开始卧底`、`开始投票`、`投票 @成员`。机器人必须能私聊所有玩家才能开始。
- 管理员发送 `语音互动 开` 启动语音聊天，`语音互动 关` 关闭。开启后群内语音会依次使用当前 AstrBot 的 STT、聊天模型和 TTS；会消耗所配置服务的额度。

## 数据与测试

持久化数据保存到 AstrBot 的 `data/lazy_sheep/lazy_sheep.sqlite3`；开发环境会使用插件同级 `lazy_sheep_data/`。运行：

```bash
python -m unittest discover -s tests -v
```

测试覆盖资源哈希、规则识别、SQLite 统计/邀请去重、赛车和卧底状态机。实际 QQ 群操作需在已连接的 NapCat 或 Lagrange 环境中验证。
